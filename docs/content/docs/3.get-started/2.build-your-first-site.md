title: Build Your First Site
description: Add two Markdown pages, resolve the active route with useContentPage, and render a typed document with an explicit 404.
---

This guide turns the `pages` collection from installation into a working home page and nested guide page.

## Create the content

```md [content/index.md]
---
title: Welcome
description: The home page for this content site.
---

# Welcome

This page comes from `content/index.md`.

[Read the guide](/guide)
```

```md [content/guide.md]
---
title: Guide
description: A second route backed by Markdown.
---

# Guide

Both pages belong to the same typed collection.
```

For a page collection mounted at `/`, `index.md` resolves to `/` and `guide.md` resolves to `/guide`.

## Add the catch-all page

```vue [app/pages/[...slug].vue]
<script setup lang="ts">
import { createError, useSeoMeta } from '#imports'
import { pages } from '~/content.config'

const { page } = await useContentPage(pages)

if (import.meta.server && !page.value) {
  throw createError({
    statusCode: 404,
    statusMessage: 'Page not found'
  })
}

useSeoMeta({
  title: () => page.value?.title,
  description: () => page.value?.description
})
</script>

<template>
  <main v-if="page">
    <ContentRenderer :value="page" />
  </main>
</template>
```

`useContentPage(pages)` resolves the current public route through the collection. It returns the normalized document and route-resolution metadata. It deliberately leaves 404 presentation and page metadata to the application.

Pass the complete document to `<ContentRenderer>`. Do not render `page.body` directly; the renderer also consumes document metadata and component context.

## Verify the result

Open:

- `http://localhost:3000/`
- `http://localhost:3000/guide`
- `http://localhost:3000/missing`

The first two routes render Markdown. The missing route returns the application's 404.

## Read documents outside route pages

Use a pure query operation with `useAsyncData` for lists and non-route reads:

```vue [app/pages/all-pages.vue]
<script setup lang="ts">
import { many } from '@lupinum/ginko-content/client'
import { pages } from '~/content.config'

const { data: items } = await useAsyncData('all-pages', () =>
  many(pages, {
    select: ['title', 'description'],
    sort: { title: 'asc' }
  })
)
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.canonicalKey">
      <NuxtLink :to="item.route.resolvedPath">
        {{ item.title }}
      </NuxtLink>
    </li>
  </ul>
</template>
```
