---
title: Add Navigation
description: Derive an ordered navigation tree from the same collection used to resolve pages.
---

Navigation comes from collection content and folder metadata. The application renders the returned tree; it does not maintain a second route list.

## Organize the content

Rename the guide into an ordered folder:

```txt
content/
  index.md
  1.guide/
    1.index.md
    2.next-steps.md
```

Numeric prefixes control order and do not appear in public paths.

```md [content/1.guide/1.index.md]
---
title: Guide
description: Start here.
---

# Guide

This folder index resolves to `/guide`.
```

```md [content/1.guide/2.next-steps.md]
---
title: Next steps
description: Continue the guide.
---

# Next steps
```

## Query navigation

```vue [app/components/SiteNavigation.vue]
<script setup lang="ts">
import { navigation } from '@lupinum/ginko-content/client'
import { pages } from '~/content.config'

const { data: items } = await useAsyncData('pages-navigation', () =>
  navigation(pages, {
    select: ['description']
  })
)
</script>

<template>
  <nav aria-label="Content">
    <ul>
      <li v-for="(item, index) in items" :key="item.path ?? `group:${index}`">
        <NuxtLink v-if="item.path" :to="item.path">
          {{ item.title }}
        </NuxtLink>
        <span v-else>{{ item.title }}</span>

        <ul v-if="item.children?.length">
          <li v-for="(child, childIndex) in item.children" :key="child.path ?? `group:${index}:${childIndex}`">
            <NuxtLink v-if="child.path" :to="child.path">
              {{ child.title }}
            </NuxtLink>
            <span v-else>{{ child.title }}</span>
          </li>
        </ul>
      </li>
    </ul>
  </nav>
</template>
```

A folder configured by `.navigation.yml` may be a structural group without its
own page. Such an item has children but no `path`, so render its label without a
link and continue through its children.

## Mount the component

```vue [app/app.vue]
<template>
  <div class="layout">
    <SiteNavigation />
    <NuxtPage />
  </div>
</template>
```

## Verify the result

The navigation should contain `/`, `/guide`, and `/guide/next-steps` in authored order. Changing a title or numeric prefix should update the tree during development.

If an item is missing, check `draft`, `navigation: false`, partial filenames beginning with `_`, and the collection source glob.
