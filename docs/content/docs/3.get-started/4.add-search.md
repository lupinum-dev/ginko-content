---
title: Add Search
description: Enable MiniSearch and add a headless search component over the same page collection.
---

MiniSearch is Ginko's default search choice for a small-to-medium content site. The index derives from collection content and ships without a live search service.

## Configure search

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/ginko-content'],
  content: {
    search: {
      engine: 'minisearch'
    }
  }
})
```

## Add a search component

```vue [app/components/SiteSearch.vue]
<script setup lang="ts">
import { useContentSearch } from '@lupinum/ginko-content/client'
import { pages } from '~/content.config'

const search = await useContentSearch({
  collection: pages,
  limit: 8
})
</script>

<template>
  <section aria-label="Search content">
    <label for="content-search">Search</label>
    <input
      id="content-search"
      :value="search.query.value"
      type="search"
      @input="search.setQuery(($event.target as HTMLInputElement).value)"
    >

    <p v-if="search.pending.value">Searching…</p>
    <p v-else-if="search.error.value">Search is unavailable.</p>

    <ul v-else-if="search.hasResults.value">
      <li
        v-for="result in search.results.value"
        :key="`${result.path}:${result.anchor || ''}`"
      >
        <NuxtLink :to="result.anchor ? `${result.path}#${result.anchor}` : result.path">
          <strong>{{ result.title }}</strong>
          <span>{{ result.excerpt }}</span>
        </NuxtLink>
      </li>
    </ul>
  </section>
</template>
```

Passing `collection: pages` also loads search sections and navigation for interfaces such as Nuxt UI's `UContentSearch`. Omit the collection when the UI only needs ranked query results.

## Verify generated output

Run a production build and preview:

```bash
pnpm build
pnpm preview
```

Search for a heading from `guide/next-steps`. Confirm that the result links to the document path and heading anchor.

If search works in development but fails in preview, inspect the generated search assets and confirm the deployment copied the complete Nuxt output.
