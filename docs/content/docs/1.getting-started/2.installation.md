---
title: Installation
description: Install @lupinum/ginko-content and create your first collection-backed page.
---

Install the module, define one collection, and render a Markdown page through that collection. By the end, `/` should show content from `content/index.md`.

## Requirements

- Node.js 20 or later
- Nuxt 4.4.7 or later
- Vue 3.5 or later

## Add the module

Ginko is published as `@lupinum/ginko-content` and should be registered under that package name.

Run the Nuxt CLI in your project root:

```bash
npx nuxi module add @lupinum/ginko-content
```

The command installs `@lupinum/ginko-content` and registers it in `nuxt.config.ts`.

If you prefer to do it by hand:

::code-group
```bash [pnpm]
pnpm add @lupinum/ginko-content
```

```bash [npm]
npm install @lupinum/ginko-content
```

```bash [yarn]
yarn add @lupinum/ginko-content
```
::

Then register the module:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/ginko-content'],
  imports: {
    autoImport: true
  }
})
```

The route example below uses Nuxt auto-imports for `useContentPage()`, so keep `imports.autoImport` enabled.

## Define a collection

Create `content.config.ts` and declare the first collection:

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@lupinum/ginko-content/config'

export const pages = defineCollection({
  type: 'page',
  source: '**/*.md'
})

export default defineContentConfig({
  collections: { pages }
})
```

## Create a content file

Add a Markdown file under `content/`:

```md [content/index.md]
---
title: Welcome
---

# Welcome

This page belongs to the `pages` collection and resolves to `/`.
```

## Render it

Add a route page that resolves the current route through the collection and renders it:

```vue [pages/[...slug\\].vue]
<script setup lang="ts">
import { pages } from '~/content.config'

const { page } = await useContentPage(pages)
</script>

<template>
  <ContentRenderer v-if="page" :value="page" />
</template>
```

`useContentPage()` resolves the current route through the collection and raises the default 404 when no page matches.

## Run the dev server

```bash
npx nuxi dev
```

Open `http://localhost:3000` — you should see the `Welcome` heading.
