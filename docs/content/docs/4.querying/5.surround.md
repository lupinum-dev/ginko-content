---
title: Surround
description: Load the previous and next documents alongside a page for prev/next navigation.
---

"Surround" means the two documents that sit before and after the current one in navigation order. It's what powers `← Previous / Next →` links at the bottom of a docs page.

## Page surround

The common path is a route-aware query that reads the current page route and returns the neighbours:

```vue [pages/docs/[...slug\\].vue]
<script setup lang="ts">
import { docs } from '~/content.config'

const { page, surround } = await useContentPage(docs, {
  surround: true,
  fallback: true
})
</script>

<template>
  <div>
    <ContentRenderer v-if="page" :value="page" />
    <nav class="flex justify-between gap-4">
      <NuxtLink v-if="surround[0]" :to="surround[0].path">
        ← {{ surround[0].title }}
      </NuxtLink>

      <NuxtLink v-if="surround[1]" :to="surround[1].path" class="ml-auto">
        {{ surround[1].title }} →
      </NuxtLink>
    </nav>
  </div>
</template>
```

`surround` contains previous and next entries:

```ts
{ prev: Document | null, next: Document | null }
```

Either side can be `null` at the edges of the tree.

## Rendering

Render it with ordinary Vue:

```vue
<template>
  <nav class="flex justify-between">
    <NuxtLink v-if="surround?.prev" :to="surround.prev.path">
      ← {{ surround.prev.title }}
    </NuxtLink>

    <NuxtLink v-if="surround?.next" :to="surround.next.path" class="ml-auto">
      {{ surround.next.title }} →
    </NuxtLink>
  </nav>
</template>
```
