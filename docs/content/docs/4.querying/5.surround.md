---
title: Surround
description: Load the previous and next documents alongside a page for prev/next navigation.
---

Surround entries are the two documents that sit before and after the current one in navigation order. They power `← Previous / Next →` links at the bottom of a docs page.

## Page Surround

The common path is a route-aware query that reads the current page route and returns semantic previous/next refs:

```vue [pages/docs/[...slug].vue]
<script setup lang="ts">
import { docs } from '~/content.config'

const { page, previous, next } = await useContentPage(docs, {
  surround: true
})
</script>

<template>
  <div>
    <ContentRenderer v-if="page" :value="page" />
    <nav class="flex justify-between gap-4">
      <NuxtLink v-if="previous" :to="previous.path">
        ← {{ previous.title }}
      </NuxtLink>

      <NuxtLink v-if="next" :to="next.path" class="ml-auto">
        {{ next.title }} →
      </NuxtLink>
    </nav>
  </div>
</template>
```

`previous` and `next` are navigation entries:

```ts
previous: ComputedRef<ContentNavigationTreeItem | null>
next: ComputedRef<ContentNavigationTreeItem | null>
```

Either side can be `null` at the edges of the tree. `surround: true` performs one documented extra request; pass `{ select: [...] }` instead of `true` to project fewer fields.

Build the two-item array yourself when a renderer expects that shape:

```vue
<script setup lang="ts">
const surround = computed(() => [previous.value, next.value])
</script>

<template>
  <UContentSurround :surround="surround" />
</template>
```

## Rendering

Render it with ordinary Vue:

```vue
<template>
  <nav class="flex justify-between">
    <NuxtLink v-if="previous" :to="previous.path">
      ← {{ previous.title }}
    </NuxtLink>

    <NuxtLink v-if="next" :to="next.path" class="ml-auto">
      {{ next.title }} →
    </NuxtLink>
  </nav>
</template>
```
