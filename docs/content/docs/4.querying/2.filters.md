---
title: Filters
description: Filter collections with explicit `where` objects.
---

Use `where` to constrain unified queries. `many`, `one`, and the other query functions come from `@lupinum/ginko-content/client` (they are not auto-imported):

```ts
import { many } from '@lupinum/ginko-content/client'

await many(articles, {
  where: { published: true }
})
```

## Equality

```ts
await many(articles, {
  where: { status: 'published' }
})
```

```ts
await many(articles, {
  where: { status: { $ne: 'draft' } }
})
```

## Comparison

```ts
await many(articles, {
  where: { date: { $gte: new Date('2026-01-01') } }
})
```

## Membership and containment

```ts
await many(articles, {
  where: { status: { $in: ['published', 'featured'] } }
})
```

```ts
await many(articles, {
  where: { tags: { $contains: 'intro' } }
})
```

## Prefix and existence

```ts
await many(docs, {
  where: { path: { $prefix: '/docs/getting-started' } }
})
```

Public queries accept `$prefix` for path-prefix matching. They do not accept
caller-provided `$regex` filters; keep regex-style matching inside trusted
provider or storage code.

```ts
await many(articles, {
  where: { cover: { $exists: true } }
})
```

## Grouped logic

```ts
await many(articles, {
  where: {
    $and: [
      { published: true },
      {
        $or: [
          { featured: true },
          { priority: { $gte: 10 } }
        ]
      }
    ]
  }
})
```

## Path sugar

Use `by: { path }` for exact path matches:

```ts
import { one } from '@lupinum/ginko-content/client'

await one(docs, {
  by: { path: '/docs/getting-started' }
})
```

## Operator reference

| Operator | Meaning |
|---|---|
| `$eq` | Equal to (also the sugar for a bare scalar value) |
| `$ne` | Not equal to |
| `$gt` | Greater than |
| `$gte` | Greater than or equal to |
| `$lt` | Less than |
| `$lte` | Less than or equal to |
| `$in` | Value is one of the given array entries |
| `$nin` | Value is none of the given array entries |
| `$contains` | Array/string contains every given entry |
| `$containsAny` | Array/string contains at least one given entry |
| `$icontains` | Case-insensitive substring match |
| `$exists` | Field is present (or absent, with `false`) |
| `$type` | Value's JavaScript `typeof` matches |
| `$regex` | Pattern match (trusted/provider code only — public queries reject caller-provided `$regex`) |
| `$prefix` | Path/string starts with the given prefix |
| `$not` | Negates a nested condition |
| `$and` | Every nested condition matches |
| `$or` | At least one nested condition matches |
