---
title: Projection
description: Keep query payloads explicit with `select`.
---

Use `select` to return only the fields you actually need.

```ts
const list = await many(articles, {
  select: ['title', 'description', 'date', 'path'],
  sort: { date: 'desc' }
})
```

Projection is inclusive on purpose:

- there is one projection API
- returned payloads stay predictable
- list queries do not silently ship full `body` trees unless you ask for them

## Single-document projection

```ts
const article = await one(articles, {
  by: { path: '/blog/hello-world' },
  select: ['title', 'author']
})
```

## Projection with paging

```ts
const page = await many(articles, {
  select: ['title', 'path'],
  sort: { path: 'asc' },
  skip: 20,
  limit: 20
})
```
