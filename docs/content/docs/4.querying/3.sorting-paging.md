title: Sorting and Paging
description: Order and page collection results with unified query options.
---

Sorting and paging stay intentionally small:

- `sort: { field: 'asc' | 'desc' }`
- `limit`
- `skip`
- `paginate()` when the UI needs total/page metadata

## Sort descending

```ts
await many(articles, {
  sort: { date: 'desc' }
})
```

## Sort with paging

```ts
await many(articles, {
  sort: { date: 'desc' },
  skip: 10,
  limit: 10
})
```

## Page metadata

Use `paginate()` for blog indexes, archive pages, and infinite-list entry points that need total count and previous/next state.

```ts
const page = await paginate(articles, {
  sort: { date: 'desc' },
  page: 2,
  limit: 10
})

page.data
page.total
page.pageCount
page.hasNext
page.nextPage
```

In Vue components, use the reactive wrapper:

```ts
const route = useRoute()
const {
  data: articles,
  page,
  pageCount,
  hasNext,
  nextPage
} = await useContentPagination(articlesCollection, {
  page: () => Number(route.query.page || 1),
  limit: 10,
  sort: { date: 'desc' }
})
```

## Multiple sort keys

Pass an ordered sort object:

```ts
await many(articles, {
  sort: {
    featured: 'desc',
    date: 'desc'
  }
})
```

## Locale-aware string ordering

```ts
await many(docs, {
  sort: { title: 'asc' },
  locale: 'de'
})
```
