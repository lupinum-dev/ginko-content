---
title: Prose components
description: Override any Markdown element by dropping a component in `components/content/`.
---

Every Markdown element renders through a `Prose*` component. Override any of them to change how that element looks — globally, across every page.

## The full list

| Element | Component |
|---|---|
| `# — ######` | `ProseH1` — `ProseH6` |
| paragraph | `ProseP` |
| link | `ProseA` |
| inline code | `ProseCode` |
| code block | `ProsePre` |
| ordered list | `ProseOl` / `ProseLi` |
| unordered list | `ProseUl` / `ProseLi` |
| blockquote | `ProseBlockquote` |
| horizontal rule | `ProseHr` |
| table | `ProseTable`, `ProseThead`, `ProseTbody`, `ProseTr`, `ProseTh`, `ProseTd` |
| image | `ProseImg` |
| emphasis / strong | `ProseEm` / `ProseStrong` |

Any component placed in `components/content/` with one of these names replaces the built-in default.

The built-in `ProseImg` renders `<NuxtImg>` automatically when Nuxt Image is available and falls back to native `<img>`. Configure this with `content.markdown.image`.

## A minimal override

Make every Markdown link use `<NuxtLink>` and add an underline on hover:

```vue [components/content/ProseA.vue]
<script setup lang="ts">
defineProps<{ href: string, title?: string }>()
</script>

<template>
  <NuxtLink
    :to="href"
    :title="title"
    class="underline-offset-4 hover:underline"
  >
    <slot />
  </NuxtLink>
</template>
```

No configuration — the module picks up the override by convention.

## Styling code blocks

Fenced code blocks render through `ProsePre`, which wraps the highlighted output:

```vue [components/content/ProsePre.vue]
<script setup lang="ts">
defineProps<{
  code?: string
  language?: string
  filename?: string
}>()
</script>

<template>
  <div class="rounded-lg border">
    <div v-if="filename" class="border-b px-4 py-2 text-sm text-muted">
      {{ filename }}
    </div>
    <div class="overflow-x-auto p-4">
      <slot />
    </div>
  </div>
</template>
```

The default slot contains the rendered code block content.

## Adding anchors to headings

A common override: put a clickable anchor next to every heading.

```vue [components/content/ProseH2.vue]
<script setup lang="ts">
defineProps<{ id?: string }>()
</script>

<template>
  <h2 :id="id" class="group scroll-mt-20">
    <a v-if="id" :href="`#${id}`" class="opacity-0 group-hover:opacity-100">
      #
    </a>
    <slot />
  </h2>
</template>
```

Repeat the pattern for `ProseH3`, `ProseH4`, etc.

## When to override

- You need a different HTML element (`<article>`, `<figure>`, etc.)
- Your design system has its own link, button, or callout primitives
- You want to add behavior — copy-to-clipboard buttons on code blocks, image lightboxes, heading anchors

For simple color or spacing tweaks, prefer CSS over overrides. A utility class on the page layout usually reaches further than a dozen component overrides.
