title: Navigation

Navigation is data, not a bundled sidebar component. Load collection navigation when you need the module-owned tree, then render it with your own Vue components or design system.

## Fetch the tree

Use `navigation(handle, options)` paired with `useAsyncData` in Nuxt pages and components:

```ts
import { useAsyncData } from '#imports'
import { navigation } from '@lupinum/ginko-content/client'
import { docs } from '~/content.config'

const { data: tree } = await useAsyncData(
  'docs-navigation',
  () => navigation(docs, { fields: ['icon', 'badge'] })
)
```

Use the endpoint when you need the same tree outside the app composable API:

```ts
const navigation = await $fetch('/api/_content/navigation', {
  query: { collection: 'docs' }
})
```

## Render one level

The returned tree contains normalized navigation items with stable `id`, `title`, `path`, and optional `children`.

```vue [components/DocsNavigation.vue]
<script setup lang="ts">
import type { ContentNavigationItem } from '@lupinum/ginko-content'

defineProps<{
  items: ContentNavigationItem[]
}>()
</script>

<template>
  <ul v-if="items.length">
    <li v-for="item in items" :key="item.path || item.title">
      <NuxtLink v-if="item.path" :to="item.path">{{ item.title }}</NuxtLink>
      <span v-else>{{ item.title }}</span>
    </li>
  </ul>
</template>
```

Use a recursive component when your docs need nested sections.

## Resolve common links

Derive common app links from the tree with plain Vue computed values instead of a dedicated composable:

```ts
const { data: tree } = await useAsyncData(
  () => `docs-navigation:${locale.value}`,
  () => navigation(docs, { locale: locale.value }),
  { watch: [locale] }
)

const flatten = (items: ContentNavigationTreeItem[]): ContentNavigationTreeItem[] =>
  items.flatMap(item => [item, ...flatten(item.children || [])])

const docsHome = computed(() => flatten(tree.value || []).find(item => item.path)?.path)
const paths = computed(() => new Set(flatten(tree.value || []).map(item => item.path).filter(Boolean)))
const isActive = computed(() => paths.value.has(route.path))
```

Returned `path` values are already localized and translated-slug-resolved. Do not wrap them in `localePath()`.

Use `useContentSearch({ collection })` only when preparing Nuxt UI search props; its `searchNavigation` output is projected for search.
