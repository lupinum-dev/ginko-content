---
title: ContentRenderer
description: Turn a parsed document into a rendered Vue component tree.
---

`<ContentRenderer>` accepts a document and renders its `body` — headings, paragraphs, code blocks, and any MDC components — as Vue.

## Basic usage

```vue [pages/docs/[...slug\\].vue]
<script setup lang="ts">
import { docs } from '~/content.config'

const { page } = await useContentPage(docs)
</script>

<template>
  <ContentRenderer v-if="page" :value="page" />
</template>
```

`:value` is the resolved document. The renderer walks its `body` tree and mounts the right components for each node.

## What it renders

| Markdown / MDC | Rendered by |
|---|---|
| `# heading` | `<ProseH1>` — `<ProseH6>` |
| paragraph | `<ProseP>` |
| `[text](url)` | `<ProseA>` |
| `` `code` `` | `<ProseCode>` |
| ```` ```lang ```` block | `<ProsePre>` |
| `- list item` | `<ProseUl>` / `<ProseLi>` |
| `| table |` | `<ProseTable>` |
| `::component` | the matching component in `components/content/` |

See [Prose components](/docs/rendering/prose-components) for the full list and how to override any of them.

## Tag

`<ContentRenderer>` defaults to wrapping output in a `<div>`. Use `tag` to change the root element:

```vue
<ContentRenderer :value="page" tag="article" />
```

Pass `tag="none"` to render without any wrapping element (useful when the parent already provides semantic structure):

```vue
<ContentRenderer :value="page" tag="none" />
```

## Excerpts

Set `excerpt` to render only the excerpt portion of a document (everything before `<!--more-->`):

```vue
<ContentRenderer :value="page" :excerpt="true" />
```

Pair this with a card layout showing a short preview that links to the full article.

## Custom components

Any component placed in `components/content/` is available inside rendered content. Use it from the page like any other MDC component:

```md [content/articles/launch.md]
::call-to-action{href="/signup"}
Sign up for free
::
```

```vue [components/content/CallToAction.vue]
<script setup lang="ts">
defineProps<{ href: string }>()
</script>

<template>
  <a :href="href" class="rounded-md bg-primary-500 px-4 py-2 text-white">
    <slot />
  </a>
</template>
```
