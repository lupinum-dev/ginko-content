---
title: Server Utils
description: Server-side unified query, sitemap, and provider helpers.
---

Server helpers are for Nitro routes, sitemap integration, and explicit reference resolution. They use the same collection model as the app composables, but require the active `event`.

## `one`

Resolve one document from server-only code.

```ts
import { docs } from '~/content.config'

const page = await one(event, docs, {
  by: { route: '/docs/intro' },
  locale: 'en'
})
```

## `many`

Resolve a list of documents from server-only code.

```ts
import { posts } from '~/content.config'

const latest = await many(event, posts, {
  where: { published: true },
  sort: { date: 'desc' },
  limit: 10
})
```

## `paginate`

Resolve one page of documents and keep total/page metadata.

```ts
const page = await paginate(event, posts, {
  page: 2,
  limit: 10,
  sort: { date: 'desc' }
})
```

## `backlinks`

Resolve source documents that reference a target document.

```ts
const byAuthor = await backlinks(event, authors, {
  by: { ref: 'jane-doe' },
  from: posts,
  sort: { date: 'desc' }
})
```

## `queryCollectionsSitemapEntries`

Generate sitemap entries from content collections.

```ts
const entries = await queryCollectionsSitemapEntries(event, {
  siteUrl: 'https://example.com'
})
```

Collections are included by default unless the collection config sets `sitemap: false`.

## Cache helpers

Cache-aware providers and adapters import helpers from `#content/server`.

```ts
import {
  contentCacheHeaders,
  vercelContentCache,
  withContentCache,
  type ContentCacheAdapter,
  type ContentCacheHint
} from '#content/server'
```

`withContentCache(data, hint)` wraps a provider method result with request cache metadata. The runtime unwraps the data for callers and records the hint for the current response.

```ts
return withContentCache(page, {
  tags: ['entry:docs:intro', 'collection:docs', 'route:/docs/intro'],
  paths: ['/docs/intro'],
  maxAge: 300,
  swr: 60
})
```

`contentCacheHeaders(hint)` converts portable freshness hints into HTTP headers. Cache adapters can use it before adding platform-specific headers such as `Cache-Tag` or surrogate keys.

`vercelContentCache({ origin, bypassToken })` is a path-only adapter for Vercel ISR on-demand revalidation. It requires explicit `paths`; tag-only invalidation must be resolved by the provider/CMS first.

## `resolveOne`

Resolve a document with a diagnostic envelope.

```ts
import { authors } from '~/content.config'

const result = await resolveOne(event, authors, {
  by: { ref: 'authors/jane' },
  locale: 'en',
  fallback: true
})
```

The envelope describes the requested selector, normalized selector, matched document, and whether locale fallback was used.
