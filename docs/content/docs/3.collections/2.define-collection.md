---
title: defineCollection
description: The signature, options, and schema patterns for declaring a collection.
---

`defineCollection({ type, source, ...options })` declares one collection. Use it inside `defineContentConfig({ collections })`.

## Signature

```ts
defineCollection(
  {
    type: 'page' | 'data'
    source: string | string[] | {
      include: string | string[]
      exclude?: string | string[]
    }
    schema?: ZodType
    strict?: boolean
    i18n?: true | {
      defaultLocale: string
      locales: string[]
    }
    sitemap?: boolean
  }
)
```

## The source glob

The source glob is resolved relative to the `content/` directory:

```ts
defineCollection({ type: 'page', source: 'articles/**/*.md' })   // all articles
defineCollection({ type: 'page', source: 'docs/**/*.md' })       // all docs
defineCollection({ type: 'data', source: 'authors/*.yml' })      // flat data directory
defineCollection({ type: 'page', source: '**/*.md' })            // everything
defineCollection({ type: 'page', source: ['guides/**/*.md', 'guides/**/*.yml'] }) // one collection, multiple globs
```

A file matches at most one collection. When globs overlap, the collection declared first wins.

Use `source.exclude` when the include glob needs a local exclusion:

```ts
defineCollection({
  type: 'page',
  source: {
    include: 'docs/**/*.md',
    exclude: 'docs/private/**'
  }
})
```

## The schema

Schemas use [Zod](https://zod.dev). Prefer Ginko's `fields` helpers for content fields that should also drive CMS editing, relation handling, and richer form controls. Plain Zod remains supported for custom validation and data shapes.

```ts [content.config.ts]
import { defineCollection, defineContentConfig, fields } from '@lupinum/ginko-content/config'
import { z } from 'zod'
```

### Common field patterns

```ts
z.object({
  title: fields.text().required(),
  description: fields.textarea(),
  slug: fields.slug({ from: 'title' }),
  draft: fields.boolean(),
  featured: fields.boolean(),
  date: fields.date().required(),
  updatedAt: fields.datetime(),
  tags: z.array(z.string()).default([]),
  status: fields.select(['draft', 'published', 'archived']),
  author: fields.object({
    name: fields.text().required(),
    avatar: fields.object({
      src: fields.image().required(),
      alt: fields.text()
    })
  })
})
```

### References to other collections

Use `fields.relation()` and `fields.relations()` to declare validated references that CMS providers can render as relation pickers. The lower-level `reference()` helper remains available for plain Zod schemas. See [References](/docs/collections/references) for the full rules.

```ts
import { defineCollection, defineContentConfig, fields } from '@lupinum/ginko-content/config'
import { z } from 'zod'

defineCollection({
  type: 'page',
  source: 'articles/**/*.md',
  schema: z.object({
    title: fields.text().required(),
    author: fields.relation('authors').required()
  })
})
```

## Strict mode

Set `strict: true` to fail the build when a matched document does not satisfy the schema:

```ts
defineCollection({
  type: 'page',
  source: 'docs/**/*.md',
  strict: true,
  schema: z.object({
    title: z.string(),
    description: z.string().optional()
  })
})
```

## Collection i18n

Collections can opt into the global i18n config, or provide their own locale set:

```ts
defineCollection({
  type: 'page',
  source: 'docs/**/*.md',
  i18n: true,
  schema
})
```

Or explicitly scope the collection:

```ts
defineCollection({
  type: 'data',
  source: 'authors/*.yml',
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'de']
  }
})
```

## Example

```ts [content.config.ts]
import { defineCollection, defineContentConfig, fields } from '@lupinum/ginko-content/config'
import { z } from 'zod'

const author = z.object({
  name: fields.text().required(),
  avatar: fields.object({
    src: fields.image().required(),
    alt: fields.text()
  }),
  bio: fields.richtext()
})

export default defineContentConfig({
  collections: {
    authors: defineCollection({
      type: 'data',
      source: 'authors/**/*.md',
      i18n: true,
      schema: author
    }),

    articles: defineCollection({
      type: 'page',
      source: 'articles/**/*.md',
      strict: true,
      schema: z.object({
        title: fields.text().required(),
        description: fields.textarea().required(),
        date: fields.date().required(),
        tags: z.array(z.string()).default([]),
        author: fields.relation('authors').required(),
        cover: fields.image()
      })
    }),

    pages: defineCollection({
      type: 'page',
      source: '*.md',
      schema: z.object({
        title: fields.text().required(),
        description: fields.textarea()
      })
    })
  }
})
```
