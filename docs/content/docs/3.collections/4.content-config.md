`content.config.ts` is the source of truth for typed collections and content-model parsing. Runtime behavior such as locale resolution, markdown rendering, and sitemap registration lives in `nuxt.config.ts` under `content`.

## Location

Place `content.config.ts` at the project root:

```ts [content.config.ts]
import { defineContentConfig } from '@lupinum/ginko-content/config'

export default defineContentConfig({
  // ...
})
```

## Top-level shape

```ts
defineContentConfig({
  collections: Record<string, Collection>
})
```

`collections` is required. Public querying, page resolution, navigation, search, and sitemap generation all start from named collections.

## collections

Declare typed collections with [`defineCollection`](/docs/collections/define-collection):

```ts
import { defineCollection, fields } from '@lupinum/ginko-content/config'
import { z } from 'zod'

collections: {
  articles: defineCollection({
    type: 'page',
    source: 'articles/**/*.md',
    strict: true,
    schema: z.object({ title: fields.text().required(), date: fields.date().required() })
  }),
  authors: defineCollection({
    type: 'data',
    source: 'authors/**/*.md',
    i18n: true,
    schema: z.object({ name: fields.text().required() })
  })
}
```

## Collection i18n

Collections can opt into locale-aware behavior directly:

```ts
collections: {
  docs: defineCollection({
    type: 'page',
    source: 'docs/**/*.md',
    i18n: true
  }),
  legal: defineCollection({
    type: 'page',
    source: 'legal/**/*.md',
    i18n: {
      defaultLocale: 'en',
      locales: ['en', 'de']
    }
  })
}
```

Global locale detection, fallback, and translated slug handling live in `nuxt.config.ts` under `content.i18n`.

## Putting it together

```ts [content.config.ts]
import { defineCollection, defineContentConfig, fields } from '@lupinum/ginko-content/config'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    authors: defineCollection({
      type: 'data',
      source: 'authors/**/*.md',
      i18n: true,
      schema: z.object({
        name: fields.text().required(),
        avatar: fields.object({
          src: fields.image().required(),
          alt: fields.text()
        })
      })
    }),

    articles: defineCollection({
      type: 'page',
      source: 'articles/**/*.md',
      strict: true,
      schema: z.object({
        title: fields.text().required(),
        description: fields.textarea().required(),
        date: fields.date().required(),
        tags: z.array(z.string()).default([]),
        author: fields.relation('authors').required()
      })
    })
  }
})
```
