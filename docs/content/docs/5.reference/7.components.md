The public component surface is small. Most apps fetch content with composables and render the parsed document with `ContentRenderer`.

## `ContentRenderer`

Render a parsed content document.

```vue
<ContentRenderer :value="page" />
```

### Props

| Prop | Type | Default | Purpose |
|---|---|---|---|
| `value` | `object` | `{}` | Parsed content document or Markdown root |
| `tag` | `string` | `'div'` | Wrapper element for rendered output |
| `excerpt` | `boolean` | `false` | Render `excerpt` instead of `body` |
| `prose` | `boolean` | runtime default | Enable or disable prose component mapping |
| `unwrap` | `boolean \| string` | `false` | Unwrap matching tags in rendered output |

Use the `empty` slot when a document has no renderable body:

```vue
<ContentRenderer :value="page">
  <template #empty>
    <p>No content found.</p>
  </template>
</ContentRenderer>
```

## `ContentRendererInline`

Render a Markdown string inline.

```vue
<ContentRendererInline value="Read the **release notes**." />
```

### Props

| Prop | Type | Default | Purpose |
|---|---|---|---|
| `value` | `string` | required | Markdown string to parse and render |
| `tag` | `string` | `'span'` | Wrapper element |
| `unwrap` | `boolean \| string` | `'p'` | Unwrap matching tags after parsing |
| `prose` | `boolean` | runtime default | Enable or disable prose component mapping |
| `components` | `object` | `{}` | Component overrides for this inline render |
