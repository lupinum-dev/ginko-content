---
title: Query API
description: Reference for one, many, paginate, resolveOne, backlinks, surround, and navigation on client and server.
---

The unified query API uses collection handles and immutable option objects. Import client operations from `@lupinum/ginko-content/client` and server operations from `@lupinum/ginko-content/server`.

## Client and server signatures

Client:

```ts
one(handle, options)
many(handle, options?)
paginate(handle, options)
resolveOne(handle, options)
backlinks(handle, options)
surround(handle, options)
navigation(handle, options?)
```

Server:

```ts
one(event, handle, options)
many(event, handle, options?)
paginate(event, handle, options)
resolveOne(event, handle, options)
backlinks(event, handle, options)
surround(event, handle, options)
navigation(event, handle, options?)
```

Localized handles require an options object with `locale` for operations where ambient route context is unavailable.

## Selectors

Single-document operations accept exactly one selector:

```ts
type ContentSelector =
  | { path: string }
  | { route: string }
  | { ref: string }
```

- `route` accepts a public application route.
- `path` accepts a content path before application locale projection.
- `ref` accepts an authored stable alias.

## `one`

Returns the first matching localized document or `null`.

```ts
const page = await one(docs, {
  by: { ref: 'guide:introduction' },
  locale: 'de',
  fallback: true,
  select: ['title', 'description']
})
```

Options: `by`, `locale`, `fallback`, `select`, and `populate`.

## `many`

Returns an array of matching localized documents.

```ts
const posts = await many(blog, {
  where: {
    tags: { $contains: 'release' },
    draft: { $ne: true }
  },
  sort: { publishedAt: 'desc' },
  limit: 20,
  select: ['title', 'description', 'publishedAt']
})
```

Options: `where`, `sort`, `limit`, `skip`, `locale`, `fallback`, `select`, and `populate`.

Without `sort`, result order is provider-defined. Always specify a sort when
presentation or pagination requires deterministic ordering.

## `paginate`

Supports honest offset and cursor modes.

```ts
const result = await paginate(blog, {
  mode: 'offset',
  page: 2,
  limit: 10,
  sort: { publishedAt: 'desc' }
})
```

Offset results contain `mode`, `data`, `page`, `limit`, `total`, `pageCount`, `hasNext`, `hasPrevious`, `nextPage`, and `previousPage`.

```ts
const result = await paginate(blog, {
  mode: 'cursor',
  after: previousEndCursor,
  limit: 10,
  sort: { publishedAt: 'desc' }
})
```

Cursor results contain `mode`, `data`, `limit`, `endCursor`, and `hasNext`. Cursor mode does not synthesize an exact total.

## `resolveOne`

Returns `{ doc, explain }`. Use it when diagnostics need the normalized selector, matched locale, and fallback decision.

```ts
const { doc, explain } = await resolveOne(docs, {
  by: { route: '/de/dokumentation/einstieg' },
  locale: 'de',
  fallback: true
})
```

## `backlinks`

Returns documents from one or more source collections that refer to a target.

```ts
const posts = await backlinks(authors, {
  by: { ref: 'author:jane' },
  from: blog,
  via: ['author'],
  sort: { publishedAt: 'desc' }
})
```

## `surround`

Returns `{ previous, next }` around one selected document.

```ts
const neighbors = await surround(docs, {
  by: { ref: 'guide:installation' },
  select: ['description']
})
```

Both entries may be `null`.

## `navigation`

Returns the collection navigation tree.

```ts
const tree = await navigation(docs, {
  locale: 'de',
  select: ['description', 'icon']
})
```

Options: `where`, `sort`, `select`, `locale`, and `fallback`.

## Fallback

`fallback` accepts `false`, `true`, `'default'`, or a readonly locale array.
Use `['en']` for one explicit fallback locale; `[]` and `false` both request
exact resolution. Single-document resolution may use fallback. List behavior
remains locale-scoped unless explicitly requested by the operation.

## Selection guarantees

Projection preserves identity plus the route and resolution envelope. Selected results retain the fields needed to identify and link the document even when the caller requests a narrow field list.

## Errors

Queries reject unsupported operators, invalid selectors, invalid pagination combinations, and provider capabilities that cannot execute the requested plan. They do not silently downgrade behavior.
