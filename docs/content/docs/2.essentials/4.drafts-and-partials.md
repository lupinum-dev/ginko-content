title: Drafts and partials
description: Hide work-in-progress and reuse content blocks across pages.
---

Two conventions let you keep files in `content/` without routing them: drafts (hidden in production) and partials (never routed, always reusable).

## Drafts

A draft is a page that exists in `content/` but is hidden from production. It's visible in development so authors can preview it.

Three ways to mark a file as a draft:

**Frontmatter flag:**

```md [content/articles/future-work.md]
---
title: Future work
draft: true
---

# Future work
```

**Filename suffix:**

```txt
content/articles/future-work.draft.md
```

**Underscore convention for entire folders** — see partials below.

Query-time filtering happens automatically: in production, drafts are excluded from `many(handle)` results and from navigation. In development, they're included and rendered with a `draft` badge if your layout opts in.

You can inspect the flag manually:

```ts
const { page } = await useContentPage(articles)

if (page.value?._draft) {
  // Render a "Draft" indicator
}
```

### Opting drafts into production

To include a draft in a specific query — for example a preview route — read the raw document:

```ts
const draft = await one(articles, {
  by: { path: route.path },
  where: { _draft: true }
})
```

## Partials

A partial is a file that's parsed and queryable but never routed. Two conventions trigger it:

**Underscore-prefixed filename:**

```txt
content/docs/
  _shared-intro.md      → partial
  getting-started.md    → /docs/getting-started
```

**Underscore-prefixed folder** — everything inside becomes a partial:

```txt
content/
  _snippets/
    install.md          → partial
    config.md           → partial
```

Use cases:

- Shared boilerplate (install instructions, legal footer) included in multiple pages
- MDC components stored as Markdown fragments
- Data-only documents consumed by page components

### Using a partial

Partials are queryable like any other document:

```ts
const intro = await one(docs, {
  by: { path: '/docs/_shared-intro' }
})
```

Render it with `<ContentRenderer>` inside any page:

```vue
<template>
  <ContentRenderer v-if="intro" :value="intro" />
</template>
```

### Partial metadata

Partials can still carry frontmatter. Use it to parameterise the fragment:

```md [content/_snippets/install.md]
---
command: npx nuxi module add @lupinum/ginko-content
---

Run the following in your project:

`{{ $doc.command }}`
```
