Essentials are the authoring rules that apply before you add much configuration: Markdown parsing, MDC components, filesystem-derived navigation, drafts, and partials.

## In this section

- [Markdown](/docs/essentials/markdown) — plain Markdown plus frontmatter
- [MDC](/docs/essentials/mdc) — embed Vue components inside Markdown
- [Navigation](/docs/essentials/navigation) — turn folders into sidebars
- [Drafts and partials](/docs/essentials/drafts-and-partials) — hide or reuse content without deleting it

Start with [Markdown](/docs/essentials/markdown) if you are writing content. Start with [Navigation](/docs/essentials/navigation) if you are building a docs layout.
