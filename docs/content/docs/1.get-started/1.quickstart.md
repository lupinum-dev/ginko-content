---
title: Quickstart
description: Go from an empty Nuxt 4 app to Markdown rendering at its own URL in about five minutes.
---

You need Nuxt 4.4.7 through Nuxt 4.x, Vue 3.5.35 through Vue 3.x, and Node.js 22.18–22.x, 24.11–24.x, or 26+.

## Install

```bash
npx nuxi module add @lupinum/ginko-content@next
```

Or install and register it yourself:

```bash [pnpm]
pnpm add @lupinum/ginko-content@next zod
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/ginko-content']
})
```

These docs describe the `0.3` prerelease on npm's `next` channel; untagged `latest` stays `0.2.1` until the stable cutover.

## Declare a collection

Create `content.config.ts` at the app root. The exported `pages` handle is what your components import instead of a string name.

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@lupinum/ginko-content/config'
import { z } from 'zod'

export const pages = defineCollection({
  type: 'page',
  source: '**/*.md',
  schema: z.object({
    title: z.string(),
    description: z.string().optional()
  })
})

export default defineContentConfig({
  collections: { pages }
})
```

## Add two Markdown files

```md [content/index.md]
---
title: Welcome
description: The home page for this content site.
---

# Welcome

This page comes from `content/index.md`.

[Read the guide](/guide)
```

```md [content/guide.md]
---
title: Guide
description: A second route backed by Markdown.
---

# Guide

Both pages belong to the same typed collection.
```

`index.md` resolves to `/` and `guide.md` resolves to `/guide`.

## Render them at their URL

One catch-all route serves every page. It resolves the current URL, throws its own 404, sets meta, and renders the document.

```vue [app/pages/[...slug].vue]
<script setup lang="ts">
import { createError, useSeoMeta } from '#imports'
import { pages } from '~/content.config'

const { page } = await useContentPage(pages)

if (import.meta.server && !page.value) {
  throw createError({
    statusCode: 404,
    statusMessage: 'Page not found'
  })
}

useSeoMeta({
  title: () => page.value?.title,
  description: () => page.value?.description
})
</script>

<template>
  <main v-if="page">
    <ContentRenderer :value="page" />
  </main>
</template>
```

> **Pass the whole document to `<ContentRenderer>`, not `page.body`.** The renderer also reads document metadata and component context, so rendering the body alone drops both.

## Run it

```bash
pnpm dev
```

Open `http://localhost:3000/` and `/guide` to see rendered Markdown, and `/missing` to see your 404.

That is the whole loop: files in, pages out. Every extra `.md` file under `content/` becomes another route.
