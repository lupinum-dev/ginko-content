---
title: Configure Sitemap and Prerender
description: Let Ginko supply content routes, Nuxt Sitemap serialize XML, and Nitro prerender eligible pages from the same route facts.
---

Ginko owns content-backed route facts. `@nuxtjs/sitemap` owns XML. Nitro owns prerender execution.

## Install sitemap support

```bash
pnpm add @nuxtjs/sitemap
```

Use a version supported by the package compatibility policy.

## Configure the owners

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@lupinum/ginko-content',
    '@nuxtjs/sitemap'
  ],
  site: {
    url: 'https://example.com'
  },
  content: {
    sitemap: true
  }
})
```

Ginko registers a content source with Nuxt Sitemap and contributes eligible content routes to Nitro prerender discovery.

## Collection defaults

- Page collections participate unless excluded by policy.
- Data collections do not participate by default.
- Drafts and partials stay out of production output.
- `sitemap: false` on authored content excludes that route from sitemap output.
- Locale variants produce alternates through canonical identity.

## Static application pages

Nuxt page localization belongs in Nuxt I18n's page configuration. Content route localization belongs in Ginko. Do not create one combined application route table for both.

## Verify generated output

```bash
pnpm generate
pnpm preview
```

Check:

- sitemap XML contains expected content routes;
- localized entries contain reciprocal alternates;
- draft, partial, and excluded routes are absent;
- nested routes have generated HTML;
- direct loading works on the target host.

The Ginko repository also contains static sitemap contract tests. Consumer applications should add equivalent assertions for their own route policy.

## Failure modes

- Enabling `content.sitemap` without installing Nuxt Sitemap.
- Generating XML independently from Ginko route facts.
- Filtering locale alternates after they are projected.
- Assuming sitemap inclusion creates a Nuxt page component.
- Using prerender output as the source of truth for content.
