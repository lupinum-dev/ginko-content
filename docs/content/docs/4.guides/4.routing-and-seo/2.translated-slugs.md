---
title: Use Translated Slugs
description: Translate content folder and file names while preserving cross-locale identity through numeric prefix chains.
---

Enable translated slugs when public content paths must use different words in each locale. Keep shared slugs when only the locale prefix changes.

## Configure translated slugs

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/ginko-content', '@nuxtjs/i18n'],
  content: {
    i18n: {
      defaultLocale: 'en',
      locales: ['en', 'de'],
      translatedSlugs: true,
      fallback: {
        de: ['en']
      }
    }
  }
})
```

## Preserve identity with prefixes

```txt
content/docs/
  en/
    1.documentation/
      1.getting-started.md
      2.installation.md
  de/
    1.dokumentation/
      1.erste-schritte.md
      2.installation.md
```

The numeric chain identifies equivalents:

- `1/1` joins `getting-started` and `erste-schritte`.
- `1/2` joins both installation pages.

The translated names determine each locale's `contentPath`. Numeric prefixes do not appear in public URLs.

## Treat prefix changes as identity changes

Changing `1.getting-started.md` to `3.getting-started.md` does not only reorder the file. It changes canonical identity.

To reorder without changing identity, use supported navigation metadata rather than changing the identity prefix chain.

## Switch languages

Use `page.route.alternates`. Do not translate slugs in the browser or replace path segments manually.

```vue
<NuxtLink
  v-for="alternate in page.route.alternates"
  :key="alternate.locale"
  :to="alternate.path"
>
  {{ alternate.locale }}
</NuxtLink>
```

## Verify

Check that each variant resolves, language switching reaches its equivalent, fallback paths are labeled, navigation merges correctly, and sitemap alternates are reciprocal.

## Failure modes

- Missing or duplicate numeric prefixes.
- Different prefix chains for translations of the same document.
- Renumbering files to change visual order.
- Translating public paths outside Ginko's variant model.
