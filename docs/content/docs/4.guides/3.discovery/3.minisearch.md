---
title: Use MiniSearch
description: Build a portable JSON search index for small-to-medium content sites and query it through useContentSearch.
---

MiniSearch is the recommended default when the search corpus can ship as a generated browser asset.

## Configure the engine

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    search: {
      engine: 'minisearch',
      ignoredTags: ['script', 'style', 'pre'],
      filterQuery: {
        draft: false,
        partial: false
      }
    }
  }
})
```

When `collections` is omitted, Ginko indexes public route-backed collections. Data collections remain excluded unless explicitly listed.

## Query the index

```vue [app/components/ContentSearch.vue]
<script setup lang="ts">
import { useContentSearch } from '@lupinum/ginko-content/client'
import { docs } from '~/content.config'

const { locale } = useI18n()
const search = await useContentSearch({
  collection: docs,
  locale,
  limit: 10
})
</script>

<template>
  <input v-model="search.query.value" type="search">

  <ul v-if="search.hasResults.value">
    <li v-for="result in search.results.value" :key="`${result.path}:${result.anchor || ''}`">
      <NuxtLink :to="result.anchor ? `${result.path}#${result.anchor}` : result.path">
        {{ result.title }}
      </NuxtLink>
      <p>{{ result.excerpt }}</p>
    </li>
  </ul>
</template>
```

Render `excerpt` as text. Visual query highlighting belongs in the UI and must not rely on backend-specific HTML.

## Size boundary

The JSON index grows with content. MiniSearch is a good default for a few hundred documents and may remain appropriate around the filesystem provider's target range, depending on body length and locale count.

Measure the generated index and first-search load. Move to Pagefind or another backend when the payload becomes an observable user cost.

## Verify

Test a production preview, not only development. Confirm generated assets load, headings produce anchors, drafts are absent, and locale scoping works.

## Failure modes

- Indexing large data collections unintentionally.
- Rendering backend excerpts as trusted HTML.
- Loading all locales when the interface displays one locale.
- Assuming a live content API is available on a static host.
