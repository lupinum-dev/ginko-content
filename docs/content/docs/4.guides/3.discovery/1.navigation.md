---
title: Build Navigation
description: Generate an ordered, locale-aware navigation tree from collection routes and folder metadata.
---

Use `navigation(handle)` to derive a sidebar, menu, or section tree from collection content.

## Organize the tree

```txt
content/docs/
  1.get-started/
    .navigation.yml
    1.index.md
    2.installation.md
  2.reference/
    1.index.md
```

```yml [content/docs/1.get-started/.navigation.yml]
title: Get Started
icon: i-lucide-rocket
```

Numeric prefixes set order without appearing in labels or paths. Folder `index.md` frontmatter can provide the same navigation metadata when the folder has a landing page.

## Query the tree

```vue [app/components/DocsNavigation.vue]
<script setup lang="ts">
import { navigation } from '@lupinum/ginko-content/client'
import { docs } from '~/content.config'

const { locale } = useI18n()

const { data: items } = await useAsyncData(
  () => `docs-navigation:${locale.value}`,
  () => navigation(docs, {
    locale: locale.value,
    select: ['description', 'icon', 'badge']
  }),
  { watch: [locale] }
)
</script>

<template>
  <nav aria-label="Documentation">
    <ul>
      <li v-for="item in items" :key="item.path">
        <NuxtLink :to="item.path">{{ item.title }}</NuxtLink>
        <DocsNavigationBranch v-if="item.children?.length" :items="item.children" />
      </li>
    </ul>
  </nav>
</template>
```

The recursive rendering component is application UI. Ginko owns the normalized tree and public paths.

## Control visibility

- `draft: true` hides a document in production.
- `navigation: false` keeps a page routable but removes it from navigation.
- A filename beginning with `_` creates a partial with no public route.
- Collection and locale options scope the entire tree.

Do not use navigation visibility as access control.

## Multiple navigation areas

Query each collection independently and place the resulting trees in the application layout. Do not merge unrelated collections by inferring URL prefixes.

## Verify

Confirm ordering, nested paths, hidden entries, active-locale titles, and direct route resolution. A navigation URL must resolve through the same collection that produced it.

## Failure modes

- A second manual array drifts from content.
- Folder metadata conflicts between `index.md` and `.navigation.yml`.
- A locale tree is queried without an explicit locale in route-less code.
- The renderer assumes only one nesting level.
