---
title: Build a Multilingual Site
description: Configure Nuxt I18n and Ginko so locale selection, fallback, translated content routes, search, and sitemap share one model.
---

Use Nuxt I18n as the application locale authority and Ginko as the content-variant authority.

## Install Nuxt I18n

```bash
pnpm add @nuxtjs/i18n
```

## Configure the modules

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@lupinum/ginko-content',
    '@nuxtjs/i18n'
  ],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US' },
      { code: 'de', language: 'de-DE' }
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default'
  },
  content: {
    i18n: {
      defaultLocale: 'en',
      locales: ['en', 'de'],
      fallback: {
        de: ['en']
      }
    }
  }
})
```

Nuxt I18n and Ginko must declare the same locale codes and default locale.

## Localize the collection

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@lupinum/ginko-content/config'

export const docs = defineCollection({
  type: 'page',
  source: 'docs/**/*.md',
  route: '/docs',
  i18n: true
})

export default defineContentConfig({ collections: { docs } })
```

## Organize shared slugs

```txt
content/docs/
  en/
    index.md
    installation.md
  de/
    index.md
    installation.md
```

Use the same locale-agnostic file path for both variants. Enable translated slugs only when public path translation is a requirement.

## Render and switch locales

```vue [app/pages/docs/[...slug].vue]
<script setup lang="ts">
import { docs } from '~/content.config'

const { page } = await useContentPage(docs, { fallback: true })
</script>

<template>
  <article v-if="page">
    <nav aria-label="Languages">
      <NuxtLink
        v-for="alternate in page.route.alternates"
        :key="alternate.locale"
        :to="alternate.path"
      >
        {{ alternate.locale }}
      </NuxtLink>
    </nav>

    <p v-if="page.resolution.usedFallback">
      This page is not available in the requested language.
    </p>

    <ContentRenderer :value="page" />
  </article>
</template>
```

## Scope lists and search

Pass the active locale to list queries in route-less contexts and to `useContentSearch`. Do not combine locale results and filter by URL prefix afterward.

## Verify

- Load exact English and German variants.
- Remove one German file and confirm the configured fallback.
- Confirm `resolution.usedFallback` and alternates.
- Confirm navigation and search remain locale-scoped.
- Confirm sitemap alternates are reciprocal when sitemap is enabled.

## Failure modes

- Defining different locale sets in Nuxt I18n and Ginko.
- Maintaining one collection per locale.
- Switching languages by replacing the URL prefix.
- Assuming list queries mix fallback content by default.
