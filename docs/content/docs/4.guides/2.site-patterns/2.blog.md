---
title: Build a Blog
description: Create typed post pages and a localized, paginated index without maintaining a second route or metadata model.
---

A blog uses a page collection for post routes and a normal Nuxt page for the index query.

## Define posts

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@lupinum/ginko-content/config'
import { z } from 'zod'

export const posts = defineCollection({
  type: 'page',
  source: 'blog/**/*.md',
  route: '/blog',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    publishedAt: z.iso.datetime(),
    tags: z.array(z.string()).default([]),
    image: z.string().optional()
  })
})

export default defineContentConfig({ collections: { posts } })
```

## Author a post

```md [content/blog/first-post.md]
---
title: First post
description: Why the content model stays collection-first.
publishedAt: 2026-07-14T08:00:00.000Z
tags:
  - architecture
---

# First post

The post body remains Markdown.
```

## Render a post

```vue [app/pages/blog/[slug].vue]
<script setup lang="ts">
import { createError } from '#imports'
import { posts } from '~/content.config'

const { page: post, previous, next } = await useContentPage(posts, {
  surround: { select: ['description', 'publishedAt'] }
})

if (import.meta.server && !post.value) {
  throw createError({ statusCode: 404, statusMessage: 'Post not found' })
}
</script>

<template>
  <article v-if="post">
    <ContentRenderer :value="post" />
  </article>
</template>
```

## Build a paginated index

```vue [app/pages/blog/index.vue]
<script setup lang="ts">
import { paginate } from '@lupinum/ginko-content/client'
import { posts } from '~/content.config'

const route = useRoute()
const pageNumber = computed(() => Math.max(1, Number(route.query.page || 1)))

const { data: result } = await useAsyncData(
  () => `blog:${pageNumber.value}`,
  () => paginate(posts, {
    page: pageNumber.value,
    limit: 12,
    sort: { publishedAt: 'desc' },
    select: ['title', 'description', 'publishedAt', 'tags', 'image']
  }),
  { watch: [pageNumber] }
)
</script>

<template>
  <article v-for="post in result?.data" :key="post.canonicalKey">
    <NuxtLink :to="post.route.resolvedPath">{{ post.title }}</NuxtLink>
    <p>{{ post.description }}</p>
  </article>
</template>
```

## Verify

Confirm descending date order, direct post loading, paging URLs, and draft exclusion in a production build.

## Failure modes

- Sorting date strings that are not normalized to one format.
- Using the file path as a permanent external ID.
- Loading every post body for an index that needs only metadata.
- Assuming `useContentPage` creates SEO metadata automatically.
