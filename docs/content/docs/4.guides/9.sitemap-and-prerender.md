---
title: Sitemap and prerender
description: Feed your content routes into @nuxtjs/sitemap XML and Nitro prerendering without keeping a second route list.
---

Install the sitemap module, set your site URL, and turn Ginko's sitemap source on:

```bash
pnpm add @nuxtjs/sitemap
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@lupinum/ginko-content',
    '@nuxtjs/sitemap'
  ],
  site: {
    url: 'https://example.com'
  },
  content: {
    sitemap: true
  }
})
```

Ginko now hands its content routes to `@nuxtjs/sitemap` for XML, and adds those routes to Nitro's prerender list. To narrow which collections appear, list them explicitly:

```ts [nuxt.config.ts]
content: {
  sitemap: {
    include: ['docs', 'posts'],
    exclude: ['internal']
  }
}
```

## What lands in the sitemap

- Page collections are included.
- Data collections are left out.
- Drafts and partials are left out in production.
- Set `sitemap: false` in a page's frontmatter to drop that one URL.
- The same page in another locale is added as an alternate for you.

## Localized static pages stay in Nuxt

Slugs for your hand-built Nuxt pages belong in Nuxt I18n's `i18n.pages`; your content URLs belong in Ginko. Keep them in their own place instead of merging both into one `sitemap.urls` or prerender array.

## Fail the build on a bad sitemap

Turn the generated XML into a release gate. This runs after `@nuxtjs/sitemap` writes the final files and fails when a sitemap is empty, drops below `minUrlsPerSitemap`, loses a required collection, or (with `requireImages`) has no images:

```ts [nuxt.config.ts]
content: {
  sitemap: {
    include: ['docs', 'posts'],
    assert: {
      enabled: true,
      mode: 'generate',
      minUrlsPerSitemap: 10,
      requiredCollections: ['docs', 'posts']
    }
  }
}
```

`mode` accepts `'generate'`, `'build'`, or `'both'`. Use `sitemaps` to override the rules for one locale such as `en-US`, and `allowEmpty` to permit empty XMLs.

> **A localized site writes `sitemap_index.xml`, not `sitemap.xml`.** i18n multi-sitemap builds emit `sitemap_index.xml` plus per-locale files. A Node preview redirects `/sitemap.xml` to the index, but a plain static host does not. Submit `/sitemap_index.xml` to search engines, or add the redirect on your host. Do not copy the index to `sitemap.xml` — that hides what you actually deployed.
