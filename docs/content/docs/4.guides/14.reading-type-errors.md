---
title: Reading type errors
description: The four most common Ginko compiler errors, what each one means, and the fix.
---

Ginko moves query mistakes from runtime to compile time. The compiler messages
are long because they carry the collection's resolved shape. This guide maps
the four messages you are most likely to meet to their cause and fix.

## `Expected 3 arguments, but got 2`

You queried an i18n collection without an options object:

```ts
const posts = await many(blog)
```

A handle declared with `i18n` makes the options argument required, because the
locale cannot be inferred outside a route context. Pass it:

```ts
const posts = await many(blog, { locale: 'de', fallback: true })
```

Route-aware reads through `useContentPage()` and `defineContentPage()` infer
the locale from the URL, so they never require this argument.

## `Type '"titel"' is not assignable to type ... Did you mean '"title"'?`

A `select`, `sort`, or populate field name does not exist on the collection's
schema. The union after `type ... is not assignable to type` lists every valid
field. Pick a name from that list; the `Did you mean` suggestion usually names
the typo.

## `Types of property 'page' are incompatible. Type 'number' is not assignable to type 'undefined'`

You passed both pagination modes to `paginate()`:

```ts
await paginate(blog, { mode: 'cursor', page: 2 })
```

Cursor pagination replaces pages with opaque cursors, so `page` must stay
undefined in cursor mode. Use `after` with the previous `endCursor`, or switch
to `mode: 'offset'`.

## `Type '"ascending"' is not assignable to type 'SortDirection | undefined'`

Sort directions are `'asc' | 'desc'`, not `'ascending'`/`'descending'`:

```ts
await many(blog, { sort: { publishedAt: 'desc' } })
```

## Runtime errors the compiler cannot see

Schema-driven checks such as populate-target mismatches, unsupported operators,
and provider capability gaps happen at runtime by design. They throw typed
errors with stable codes; the [errors reference](/docs/reference/errors) lists
every code and its meaning.
