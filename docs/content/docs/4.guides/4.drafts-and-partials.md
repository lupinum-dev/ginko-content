---
title: Drafts and partials
description: Hide unfinished pages with draft, and keep reusable snippets off the URL map by prefixing the filename with an underscore.
---

Set `draft: true` to keep an unfinished page out of production:

```md [content/blog/upcoming-release.md]
---
title: Upcoming release
draft: true
---

# Upcoming release
```

You see this page in `nuxt dev`. In production it disappears everywhere: no route, no navigation entry, no search result, no sitemap URL. Delete the `draft` line when the page is ready.

> **There is no way to view a draft on a deployed site.** Production serves a sealed content snapshot, so a deployed draft stays hidden even to you. If editors need to preview unpublished pages on production, that is a job for a CMS provider, which owns its own login and published-versus-preview logic. See [Providers](/docs/guides/providers).

## Reuse a snippet without giving it a URL

Prefix the filename with `_` to make it a partial. Other content can pull it in, but it never gets a URL, in `nuxt dev` or in production:

```txt
content/
  guides/
    installation.md
    _shared-requirements.md
```

## Keep a page off the menu

Set `navigation: false` when a page should stay reachable but drop out of the generated menu:

```md
---
title: Direct-link reference
navigation: false
---
```

The page still has a URL and still shows up in search. This hides a link, nothing more. It is not access control, so do not use it to keep private content private.
