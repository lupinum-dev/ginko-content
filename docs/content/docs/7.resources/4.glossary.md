title: Glossary
description: Canonical definitions for the content, route, localization, query, provider, search, and deployment terms used by Ginko.
---

Use these terms consistently in documentation, diagnostics, and application code.

## Content model

**Collection**  
A named owner for documents with one source, kind, schema, route policy, localization policy, and typed handle.

**Collection handle**  
The typed value returned by `defineCollection` and passed to public query operations.

**Page collection**  
A collection whose documents own content routes.

**Data collection**  
A collection of queryable records that does not produce public routes by default.

**Document envelope**  
The normalized identity, route, and resolution fields attached to a query result.

**Partial**  
A source file beginning with `_` that can be processed but never becomes a public route.

**Draft**  
A document marked `draft: true`, visible in development and hidden from normal production surfaces unless preview explicitly enables it.

## Identity and routes

**Canonical key**  
An opaque locale-agnostic join key shared by variants of one document. It is not a URL.

**Ref**  
An optional human-authored stable alias used to identify and relate content.

**Content path**  
The locale-specific route path before Nuxt locale-prefix projection.

**Resolved path**  
The canonical public route for the returned document variant.

**Route variant**  
One locale-specific content path for a canonical document.

**Translated slug**  
A locale-specific file or folder name joined to other variants through numeric prefix identity.

## Localization

**Requested locale**  
The locale the caller or route asked for.

**Resolved locale**  
The locale of the document actually returned.

**Fallback**  
Resolution of an allowed locale variant when the requested variant is absent.

**Alternate**  
A public locale route labeled as a concrete variant or fallback.

## Providers and derived data

**Provider**  
The server adapter that owns source access and returns raw documents and route facts.

**Provider capability**  
An advertised query operator or pagination mode that the provider contract suite must prove executable.

**Derived surface**  
Navigation, search, sitemap, prerender, or cache output that can be rebuilt from canonical content.

**Cache hint**  
Provider-supplied tags, paths, and lifetime metadata collected during a request.
