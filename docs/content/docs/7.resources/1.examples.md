Use repository examples to verify one focused behavior. Use playgrounds to explore a complete application.

## Maintained examples

| Outcome | Workspace path | Run |
| --- | --- | --- |
| Render a first page | `examples/essentials/hello-world` | `pnpm example essentials/hello-world` |
| Filter with `where` | `examples/queries/where` | `pnpm example queries/where` |
| Project fields | `examples/queries/only` | `pnpm example queries/only` |
| Exclude fields | `examples/queries/without` | `pnpm example queries/without` |
| Skip and limit | `examples/queries/skip-limit` | `pnpm example queries/skip-limit` |
| Fetch navigation | `examples/navigation/fetch-content-navigation` | `pnpm example navigation/fetch-content-navigation` |
| Use route-backed content | `examples/navigation/use-route` | `pnpm example navigation/use-route` |
| MDC props and slots | `examples/mdc/*` | `pnpm --dir examples/mdc/<name> dev` |
| Custom transformer | `examples/advanced/transformer` | `pnpm example advanced/transformer` |
| CMS cache contract | `examples/advanced/cms-cache-contract` | `pnpm example advanced/cms-cache-contract` |

## Playgrounds

- `playground/ginko-basic` — core page, query, and rendering behavior.
- `playground/ginko-i18n` — locale variants, fallback, and translated routes.
- `playground/ginko-search` — MiniSearch behavior.
- `playground/ginko-search-i18n` — locale-scoped search.
- `playground/ginko-provider-search` — provider-owned search.

Run the default playground from the workspace root:

```bash
pnpm dev
```

Run another playground with its workspace scripts:

```bash
pnpm --dir playground/ginko-i18n dev
```

## Choosing an example

Start with the smallest example that demonstrates the behavior. Copying a full playground into an application also copies unrelated decisions and makes debugging harder.

Examples are executable documentation. If an example and a prose page disagree, treat the public types and passing example as evidence and correct the stale page.

## Verify examples

Repository maintainers run:

```bash
pnpm examples:build
pnpm typecheck:examples
```
